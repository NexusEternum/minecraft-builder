# Minecraft Epic Inventions

Modular build photos for Epic Inventions training data.

## Strategy

- **Train now (32³):** Inventive Details modules only
- **Save for later:** Full mega-scenes @ **150³**; oversized detail modules @ **100³**
- **Photos:** Full book spreads are fine — no cropping required. Training uses procedural `.npz` voxels, not page images. One spread photo can reference many modules.
